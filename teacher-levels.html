About this page
A read-only directory of partner-school teachers and the appraisal level each is observed against. The level decides which F2 items are in scope on Class Observation Entry — 30 items at Induction, up to 45 at Lead — so it is worth knowing before a school visit. The count on the right is how many observations Eduversal has shared with that teacher.
You are signed in as an administrator, so the level dropdowns are live — changing one writes appraisal_level on that teacher's profile straight away. A teacher left at not set is scored as Induction. Levels are set on the teacher's profile by an administrator (appraisal_level on users). Only a central_admin can change them — a teacher showing not set is scored as Induction.
