What this page does
This page lets any CentralHub user host a self-contained HTML dashboard. Your file is displayed inside a secure sandbox, so it is safe to share widely. You choose the visibility: Public (anyone with the link, no login), CH only (signed-in Eduversal users), or Private (only you).
Security note — uploaded HTML runs in an isolated sandbox and cannot access Eduversal data, your login session, or other pages. Keep dashboards self-contained: embed your data and chart libraries directly in the file (live Firestore data is not available inside the sandbox).
